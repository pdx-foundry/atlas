declarations, modifiers, modifier categories, generated modifier families, the loaded modifier
table, scopes and scope links, localization, on_actions, game rules and defines. The live command

No entry-scope rule is established. Every followed call site supplies at least one self link
(`root` or the `from` chain points back to its own scope) or an unresolved scope, and Native states
that what script sees through a self link is outside its answer. The 1,514 on_action and 884
game-rule claims therefore keep their `replace_scopes` questions open. Native gaps have no owner
here: no open ticket owns the unjoined modifier generation sites, the call sites that the callback
method does not follow, or the 80 define readers beyond the table-search limit.

The loaded modifier table (45,578 names: 571 declared, 5,432 generated by a returned family,
39,576 unexplained) is a content observation. The snapshot keeps only its counts, under
`content:installation`; the names stay in the recorded answer.

## Milestone 3 exit gate

**Met.** Each of the five `script-docs` logs and each config name list has an engine-derived
answer in the snapshot, with its gaps in the ledger, and the per-area figures are above. Every
effect, trigger and loaded modifier in the logs is in the snapshot; every log scope link and
localization entry is too. The open questions are the gaps listed above, each with its owner
where one exists.

## Reproduce

```sh
cargo run --release --locked -- snapshot /path/to/Stellaris .scratch/sdk-570/answers .scratch/sdk-570/snapshot.json
cargo run --release --locked -- ledger --config "$PDX_CONFIG_PATH" \
  --snapshot .scratch/sdk-570/snapshot.json --output .scratch/sdk-570/reports
cargo run --release --locked -- compare "$PDX_CONFIG_PATH" .scratch/sdk-570/snapshot.json \
  .scratch/sdk-570/cmp --script-docs "$PDX_CONFIG_PATH/../script-docs/v4.5.0" \
  --defines /path/to/Stellaris/common/defines/00_defines.txt \
  --defines /path/to/Stellaris/common/defines/00_defines_additional_content.txt \
  --answers .scratch/sdk-570/answers
ATLAS_RULE_SNAPSHOT=.scratch/sdk-570/snapshot.json \
  cargo test --locked --test full_config -- --ignored
```

The `ledger` and `compare` commands exit 2 because the config revision has 19 source diagnostics.
The full-config gate pins the config and snapshot identities, the counts and both report digests.
